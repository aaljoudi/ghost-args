# Changelog

## 0.1.0

- Show positional argument hints from an executable script's second-line usage comment.
- Handle quoted arguments and paths, commands on PATH, home-relative paths, environment assignments, pipelines, and common redirections.
- Preserve ghost text owned by other Zsh plugins and reject terminal control characters in usage metadata.
- Add user-local installation, startup-file backups, repeatable updates, and uninstall support.
- Add automated parsing, installation, and interactive terminal tests.
